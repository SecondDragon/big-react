# react-demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a standard Vite + React (JS) project at `demos/react-demo` that references the local build output via `file:` protocol for debugging the self-built React.

**Architecture:** The demo lives entirely outside the pnpm workspace (`pnpm-workspace.yaml` scoped to `packages/*`). It's a standalone Vite project whose `react` and `react-dom` dependencies point to `dist/node_modules/` via `file:` protocol. Deleting `demos/react-demo` leaves zero impact.

**Tech Stack:** Vite (react template, JS), pnpm

---

### Task 1: Scaffold and configure react-demo

**Files:**
- Create: `demos/react-demo/` (generated by Vite template)
- Modify: `demos/react-demo/package.json`

- [ ] **Step 1.1: Generate Vite react template**

```bash
cd d:\BaiduNetdiskDownload\B站卡颂从0实现React18\big-react
pnpm create vite demos/react-demo --template react
```

Expected: `demos/react-demo/` is created with `package.json`, `index.html`, `src/`, `vite.config.js`.

- [ ] **Step 1.2: Delete generated node_modules and lock file**

```bash
cd demos/react-demo
rm -r -fo node_modules
rm -f pnpm-lock.yaml package-lock.json yarn.lock
```

Expected: clean directory, no leftover deps from the template generator.

- [ ] **Step 1.3: Replace react/react-dom deps with file: protocol**

Edit `demos/react-demo/package.json`. Change the `dependencies` section from:

```json
"dependencies": {
  "react": "^18.2.0",
  "react-dom": "^18.2.0"
}
```

to:

```json
"dependencies": {
  "react": "file:../../dist/node_modules/react",
  "react-dom": "file:../../dist/node_modules/react-dom"
}
```

- [ ] **Step 1.4: Install dependencies**

```bash
cd demos/react-demo
pnpm install
```

Expected: pnpm creates symlinks in `demos/react-demo/node_modules/react` and `node_modules/react-dom` pointing to `../../dist/node_modules/react` and `../../dist/node_modules/react-dom`.

- [ ] **Step 1.5: Verify it works**

```bash
pnpm run dev
```

Expected: Vite dev server starts. Open `http://localhost:5173/`. Confirm the default Vite + React page renders in browser (it will use your self-built React for rendering).
