📋 事件流速查表

一、事件流三阶段

阶段eventPhase方向addEventListener 参数典型用途
捕获 (Capture) 1 根 → 目标 ↓ true 或 { capture: true } 拦截事件、日志收集
目标 (Target) 2 停驻 按注册顺序触发 常规点击处理
冒泡 (Bubble) 3 目标 → 根 ↑ false（默认） 事件委托、90%日常开发

二、关键 API 速查

addEventListener 选项

选项类型效果
captureboolean在捕获阶段触发
onceboolean触发一次后自动移除
passiveboolean声明不会调用 preventDefault()
signalAbortSignal通过 AbortController 移除

Event 对象关键属性

属性/方法说明
target触发事件的源元素
currentTarget当前监听器绑定的元素
eventPhase当前阶段：1/2/3
stopPropagation()阻止传播，但同元素后续监听仍执行
stopImmediatePropagation()阻止传播 + 阻止同元素后续监听
preventDefault()阻止默认行为（如链接跳转）

三、常见不冒泡的事件

以下事件不会冒泡，无法用于事件委托，必须在目标元素上直接绑定：

事件说明替代方案
focus元素获得焦点用 focusin（会冒泡）代替
blur元素失去焦点用 focusout（会冒泡）代替
mouseenter鼠标进入用 mouseover（会冒泡）代替
mouseleave鼠标离开用 mouseout（会冒泡）代替
scroll元素滚动不可委托，但可用 passive: true 优化
load / error资源加载/错误可在捕获阶段通过 window 捕获

五、事件 → Scheduler 优先级映射表

事件类型分类Scheduler 优先级数值含义
